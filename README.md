# WHPP Learn

Бесплатный интерактивный курс веб-разработки для начинающих: **27 уроков** по HTML, CSS и основам JavaScript с финальным проектом.

**https://learn.whpp.site**

## Как устроен курс

Каждый урок — это связка из четырёх частей:

1. **Теория** — короткое объяснение простыми словами, с акцентом на «почему так».
2. **Живой пример** — код и его результат рядом, на одной странице.
3. **Задание** — редактор кода прямо в браузере: пишите, запускаете, видите результат.
4. **Автопроверка** — система проверяет ваш результат по конкретным пунктам и отмечает урок пройденным.

Прогресс сохраняется в браузере (localStorage), регистрация не нужна.

## Программа

- **Модуль 1. HTML** (10 уроков) — структура страницы, текст, ссылки, картинки, списки, таблицы, формы, семантика.
- **Модуль 2. CSS** (10 уроков) — селекторы, цвета и текст, блочная модель, классы, flexbox, grid, позиционирование, адаптив, эффекты.
- **Модуль 3. JavaScript** (5 уроков) — первый скрипт, события, стили через JS, ввод и условия, мини-проект «Счётчик».
- **Модуль 4. Финальный проект** (2 урока) — сайт-визитка целиком и подготовка к публикации.

## Технологии

Next.js 15, React 19, Tailwind CSS 4. Контент курса — типизированные модули в `src/lib/course/`, движок уроков (редактор, предпросмотр в iframe, проверки) — `src/lib/engine.tsx`.

## Разработка

```bash
npm install
npm run dev
```
